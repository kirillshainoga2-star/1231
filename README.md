# ВЕЛЮР — Android-обёртка (WebView)

Это исходник Android-приложения, которое открывает приложение ВЕЛЮР на Perchance
в нативном окне (без адресной строки браузера) и отдаёт его как обычный **APK**.

Собрать APK **внутри Perchance нельзя** — для этого нужен Android-сборщик (Gradle + Android SDK).
Ниже три пути, любой из них даёт настоящий `.apk`.

## 1. GitHub Actions (без установки инструментов, бесплатно)

1. Создай новый репозиторий на github.com (можно приватный).
2. Распакуй этот архив и залей **всё содержимое** в репозиторий (через веб-интерфейс:
   «Add file → Upload files», перетащить файлы и папки; папку `.github` — тоже).
3. Вкладка **Actions** → слева «Build APK» → **Run workflow**.
4. Через 2–4 минуты открой завершившийся запуск → внизу **Artifacts** → `VELYUR-apk` → скачай
   `app-debug.apk`, перекинь на телефон и открой (разреши «Установка из неизвестных источников»).

## 2. Android Studio (на компьютере)

1. Android Studio → **File → Open** → папка из архива.
2. Дождись синхронизации Gradle (он сам создаст wrapper).
3. **Build → Build Bundle(s)/APK(s) → Build APK(s)** → `app/build/outputs/apk/debug/app-debug.apk`.

Или из консоли (нужны JDK 17 и Android SDK):

```
gradle wrapper
./gradlew assembleDebug
```

## 3. Онлайн-конвертеры (быстрее всего, но с рекламой и лимитами)

Сервисы вида webintoapp.com / median.co собирают APK просто из ссылки на страницу.
Вставь туда публичную ссылку приложения (`https://perchance.org/<имя>`), нажми «Build»,
скачай Debug APK и открой файл на телефоне.

## Что внутри

- `app/src/main/java/org/velur/app/MainActivity.java` — WebView-обёртка: тёмная тема,
  прогресс-бар, кнопка ⚙ (изменить адрес / обновить / открыть в браузере), обработка «назад»,
  разрешения камеры/микрофона, выбор файлов.
- Адрес приложения хранится в настройках телефона (`SharedPreferences`, ключ `app_url`).
  При первом запуске показывается экран ввода адреса: можно ввести как полную ссылку
  (`https://perchance.org/velur`), так и просто имя генератора (`velur`).
- `minSdk 26`, `targetSdk 34`, AGP 8.1.4, Gradle 8.2, Java 17.

## Важно про имена файлов в репозитории

Perchance не разрешает хранить файлы с именем, начинающимся с точки, поэтому в исходнике здесь:

| здесь                            | должно лежать в архиве/репозитории     |
|----------------------------------|----------------------------------------|
| `gitignore.txt`                  | `.gitignore`                           |
| `github-workflows-build-apk.yml` | `.github/workflows/build-apk.yml`      |

При скачивании архива из приложения (кнопка 📲 → «APK-проект») имена уже правильные.
